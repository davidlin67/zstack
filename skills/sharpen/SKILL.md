name: sharpen
description: "Make a task deeper, not bigger, then rewrite the prompt. Use for $sharpen."
---

Deepen the user's task without expanding its scope. Before rewriting the prompt:

1. Say what a top professional in this field would do that the request leaves out.
2. Name the rawest material they would start from instead of what has already been digested for me.
3. Name the specific methods and tools they would use.
4. Say what independent evidence would show that the result is correct.

Then rewrite the prompt to ask for those improvements.

Have the rewritten prompt ask the agent to prototype any choice an experiment can settle and recommend an option based on what it observed. Leave product or preference choices that no experiment can settle to the user.
